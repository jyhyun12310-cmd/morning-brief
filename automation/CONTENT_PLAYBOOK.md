# 카드뉴스 원고 작성·편집 기준
최종 개정: 2026-10-20. 다음 신규 원고부터 오전·오후·속보에 공통 적용한다.
주제·중복·하루 최대 1편은 EDITORIAL_GUIDE.md를, 데이터·길이·레이아웃은 각 CONTRACT와 현재 검증 코드를 따른다. 본 문서는 그 안에서 원고 품질을 판정하는 최우선 기준이다.

## 승인된 이미지 스타일과 누적 개선 (2026-10-20 20:44 사용자 피드백)

사용자는 이 대화에서 보여준 아마존·3M 5장 이미지 시안을 보고 “훨씬 좋네 이런식으로 하라고”라고 승인했다. 다음 제작의 시각적 기준은 이 시안의 **큰 제목, 강한 대비, 핵심 구절의 파란 강조, 메시지를 설명하는 서로 다른 이미지, 한 장 한 이야기**다. 아래 과거의 색·사진 배치 선호와 충돌하면 이 최신 선호를 우선한다. 해당 시안은 미게시 디자인 참고이며 새 사건·당일 게시·정상 workflow preview 검수로 간주하지 않는다. 아마존·3M 소재와 숫자·상자·열쇠·고리 구도를 이후 게시물에 복제하지 않는다.

### 유지할 시각적 기준
- 4:5 세로 화면에서 제목을 가장 먼저 읽게 한다. 굵고 큰 한글 제목, 짧은 본문, 의미 단위 줄바꿈, 충분한 여백을 사용한다. 모바일 가독성을 위해 본문을 억지로 줄이지 않는다. 현재 계약의 장수·제목 줄 수·필드 제한은 실제 코드 변경과 검증 전까지 유지한다.
- 따뜻한 오프화이트·짙은 검정과 코발트 한 가지 강조를 기본으로 삼는다. 밝은 장과 어두운 장은 내용의 전환에 맞춰 사용할 수 있다. 핵심 제목 일부를 파랗게 강조할 수 있지만 모든 글자에 효과를 넣거나 매일 색을 바꾸는 일을 개선으로 세지 않는다.
- 매 장의 핵심을 보여주는 시각 요소 하나를 먼저 정한다. 실물 제품·시설 사진, 개념을 설명하는 편집 일러스트, 검증된 비교 중 메시지에 맞는 것을 고른다. 장마다 다른 이미지와 구도를 쓰고 같은 사진의 크롭·색 변경으로 다양성을 가장하지 않는다. 장식용 주가 그래프·관련 없는 로고 나열은 금지한다.
- 개념 일러스트는 실제 사건 현장·공식 제품 사진·공식 계약 문서로 오인시키지 않는다. 정확한 수치·표·차트·공시 문구는 검증된 데이터와 결정적 렌더링으로 표현한다. 이미지 생성 결과를 금융 사실의 근거로 쓰지 않는다. 출처 날짜·페이지 순서·계정명과 최종 한글·숫자를 직접 확인한다.
- 이 문서의 기준 저장과 제작 코드 적용은 별개다. 현재 GitHub 렌더러가 지원하지 않는 이미지 생성·업로드·배치가 연결됐다고 주장하지 않는다. 운영 경로 변경은 별도 구현·검증이 필요하며, 별도 유료 AI API·새 계정·비밀키·게시 잠금 우회를 허용하지 않는다. 실제 게시에는 계속 정상 preview artifact의 전체 이미지 검수와 동일 바이트 게시 절차를 적용한다.

### 매회 이전 편보다 나아지게 만드는 편집 절차
1. 작성 전에 최근 5편의 상세 원고·실제 카드 이미지·저장된 editorial_review와 최신 사용자 피드백을 읽는다. 못 읽은 범위는 확인한 것으로 처리하지 않는다. 제목 문형, 도입, 비유, 사진·구도, 장별 반복, 마지막 판단에서 약점 1~2개를 구체적으로 고른다.
2. 실제 오늘의 주요 후보를 비교하며 이번 사건만의 흥미를 찾는다. 뜻밖의 거래 조건, 익숙한 사업의 의외의 작동 방식, 돈을 받는 쪽과 부담하는 쪽의 차이, 중요한 선택의 대가 중 근거가 있는 관점을 고른다. 재미를 위해 대립·인과·대중 반응을 만들어내지 않는다.
3. 서로 다른 관점의 제목 후보 세 개를 비교하고 첫 두 장에서 답한다. 뒤의 장은 새 근거·설명·다른 이해관계를 더한다. 문장만 “더 자극적으로” 고치거나 같은 반전형 제목·마무리를 매일 반복하지 않는다.
4. 이번 편에서 실험할 개선 한 가지를 고른다. 예: 표지를 더 구체적인 동사로 바꾸기, 복잡한 거래를 정확한 비유 하나로 풀기, 불필요한 숫자 덜기, 핵심을 보여주는 피사체 바꾸기, 끝 장의 판단을 사건에 맞게 구체화하기. 이미 잘 읽히는 브랜드·가독성은 유지한다.
5. 실제 최종 이미지 전체를 열어 이전 편과 비교한다. 더 짧기만 한지, 더 요란하기만 한지, 첫 화면에서 읽을 이유가 생겼는지, 뒤쪽에 새 설명이 있는지 확인해 한 번 더 퇴고한다. 코드 검사와 작성자 사실검증, 이미지 육안 검수는 서로 대신하지 않는다.
6. 기존 summary.editorial_review의 improvement/reason/application/avoided_repetition 안에 참고한 이전 편, 발견한 약점, 실제 바꾼 위치, 다음에 보완할 점을 계약 길이 안에서 간결하게 남긴다. 새 필드·독립 journal을 임의로 추가하지 않는다. 다음 실행은 이 기록을 읽어 이어간다. 읽지 않은 과거 글이나 수행하지 않은 실험을 기록하지 않는다.
7. 실제 도달·저장·공유 등 분석 자료를 확보한 경우에만 게시 후 경과 시간과 지표 정의를 맞춰 참고한다. 자료가 없으면 사용자 피드백·원고·가독성 검토로만 평가한다. 매일 조회수가 오른다거나 스스로 모델을 학습시켰다고 주장하지 않는다. 개선 내용은 게시 완료 후 이 채팅에 한 줄로 보고하고 카드·캡션에 작업 보고를 넣지 않는다.

매일은 검토·개선의 기회이지 게시 의무가 아니다. 기존 통합 하루 최대 1편, 적격 소재가 없으면 0편, 신선도·중복·속보 즉시성·사실검증은 유지한다. 오늘 승인된 시안을 자동으로 게시하거나 이미 공개한 글을 고쳐 재게시하지 않는다.

## 계정의 목소리 — 짧은 경제 이야기 (2026-10-20)
사용자는 정확해도 재미없는 보고서형 글 대신 재미와 분위기가 있는 콘텐츠를 요청했다. 이 계정은 발표를 옮겨 적는 요약장이 아니라, 중요한 사건에서 **돈이 갈리는 지점과 독자가 놓치기 쉬운 이유를 짚는 짧은 경제 이야기**를 쓴다. 차분하지만 날카롭게, 쉬운 단어와 구체적인 동사로 설명한다. 자극적인 말의 강도가 아니라 확인된 이해관계·선택·예상과 결과의 차이로 흥미를 만든다.

- 한 편의 중심은 한 가지다. 누가 어떤 선택을 했고 누구의 매출·원가·거래 조건이 달라졌는지, 또는 어떤 익숙한 해석이 이번 사실에 맞지 않는지를 고른다. 모든 소재에 억지 승자·패자나 반전을 만들지 않는다.
- 재미를 이유로 중요도·새로움·넓은 영향·속보 즉시성 기준을 낮추지 않는다. 흥미로운 작은 종목으로 하루 슬롯을 채우지 않는다.
- 원고와 시각적 제작 방향은 위 최신 승인 기준으로 개선한다. 현행 장수·필수 항목·길이·출처·게시 검수는 유지하며 제작 지침 변경만으로 렌더러 변경이 끝났다고 주장하지 않는다. 기존 게시물·운영 inbox를 고치거나 과거 소재를 다시 게시하지 않는다.
- 조회수·도달·저장·공유를 확인하지 않았다면 흥행·알고리즘 효과를 약속하지 않는다. 이 기준은 편집 방향이지 검증된 성과 공식이 아니다.

## 1. 쓸 만한 이야기인가
먼저 현재 국내·미국 시장 주요 의제를 검색해 실제 후보를 비교한다. 각 후보의 새 사실 / 넓은 투자자층과 연결되는 근거 / 지금의 쟁점 / 보류 이유를 내부 메모한다. 읽지 않은 후보나 관심도를 만들지 않는다.
"이 뉴스로 독자의 기존 판단이 무엇에서 달라지는가"에 구체적인 한 문장으로 답해야 한다. 숫자만 새롭거나 기업명만 유명하거나 투자 상식만 설명하는 소재는 탈락시킨다.
게시 횟수를 채우지 않는다. 같은 이야기의 주체·숫자만 바꾼 후속편도 탈락시킨다.

속보는 중요도 외에 **다음 정기 선별까지 기다릴 때 정보 가치가 크게 줄어드는 이유**가 있어야 한다. 예상 밖의 정책 결정·핵심 지표 결과·거래 중단·시스템 위험 등 확인된 변화로 설명한다. 정례 실적은 중대한 전망 변경 등 즉시성이 따로 입증될 때만 속보로 다룬다. 자정이 지났다는 이유로 새 슬롯부터 채우지 않는다. 즉시성이 약한 기업 실적은 다음 오전 실행에서 다른 후보와 다시 비교하며, 미리 게시를 예약하거나 재탕을 보장하지 않는다.
이는 경과 시간만으로 제외하는 규칙이 아니다. 발표 후 3시간 제한은 다시 도입하지 않으며 정확한 시각이 없으면 확인된 발표일을 사용한다.

## 2. 제목보다 결론을 먼저 쓴다
카드를 나누기 전에 아래 세 줄을 쓴다.
- 지금 확인된 변화:
- 이 변화가 중요한 이유:
- 현재 가능한 해석과 그것을 바꿀 가장 중요한 조건:

이어 내부 메모에 두 줄을 더 쓴다. (독자가 놓칠 대목) 이 사실을 제목만 보면 무엇을 잘못 이해하기 쉬운가? (읽고 얻을 것) 본문에서 어떤 구체적인 이유로 그 오해를 풀 것인가? 시장 예상이나 대중의 생각을 조사하지 않았다면 “시장은 몰랐다”, “모두 속았다”라고 쓰지 않는다. 가능한 오해와 실제 관측된 기대를 구분한다.
이 세 줄이 두루뭉술하면 아직 원고를 만들지 않는다. "영향이 있을 수 있다 / 지켜볼 필요가 있다"만 남는 경우 원문과 초점을 다시 검토한다.
분명한 해석은 확정적인 주가 예측이나 매수·매도 지시를 뜻하지 않는다. 사실·회사 전망·작성자의 해석을 구분한다.

## 3. 표지에서 읽을 이유와 첫 답을 준다
제목 후보 세 개는 단어만 바꾸지 말고 서로 다른 관점으로 쓴다. ① 실제로 달라진 돈·거래 조건 ② 근거로 확인된 대비나 놓치기 쉬운 범위 ③ 중요한 선택과 그 대가 가운데 사건에 맞는 관점을 비교한다. 사실에 없는 대비를 만들 필요는 없다. 주체와 구체적인 쟁점, 읽고 얻을 답이 가장 빨리 드러나는 하나를 고른다.
표지는 “실적 발표 / 정책 변경”이라는 주제명이 아니라 이번 사건만의 한 문장이어야 한다. 추상 명사인 “효과·영향·전망·시사점”을 겹치지 말고 가능하면 “벌다·쓰다·줄이다·막다·미루다” 같은 실제 행동으로 바꾼다. “매출 신기록”을 “이익 신기록”으로 바꾸는 식의 의미 왜곡은 금지한다. 막연한 “어떻게 될까”, “내 종목은 괜찮을까”, “핵심 정리”는 쓰지 않는다.
제목은 기존 두 줄 제한 안에서 한 번에 읽히게 쓴다. 큰 숫자는 규모 자체가 쟁점일 때만 남긴다. 반전이 없으면 중요한 결정 자체로 시작한다. 느낌표·물음표·유행어를 붙여 흥미를 대신하지 않는다.
첫 1~2장에서 답한다. 결론을 마지막 장까지 숨기지 않는다. 같은 "A는 늘었는데 B는 왜 줄었나" 틀도 연속 반복하지 않는다.
제목에 없는 주체·기간·비교 기준은 같은 장에서 바로 보충한다. 단지 클릭을 위해 폭락·급등·수혜 기업·인과관계를 만들어내지 않는다.

### 답을 준 뒤에도 이야기가 앞으로 가게 한다
첫 두 장에서 핵심 답을 준 뒤, 뒤쪽은 그 이유·다른 이해관계·해석을 바꾸는 근거로 깊어진다. 다음 장으로 넘기게 하려고 핵심 단서나 결론을 숨기지 않는다.
- 3장: 확인된 결정과 독자가 놓칠 대목 → 실제로 바뀌는 부담·거래 구조 → 현재 판단과 이를 뒤집을 결정적 조건. headline/impact/watch 계약은 유지한다.
- 5장: 한 사건의 변화·이유·업종 차이·관련 일정·판단을 해당 고정 레이아웃에 맞춘다. 관련 없는 시황·종목을 끼워 장수를 채우지 않는다.
- 7장: 첫 답을 준 다음 사업 구조·같은 기준의 비교·숨은 비용이나 범위·조건으로 이해를 넓힌다. 각 장에 독립적인 근거가 없으면 소재를 건너뛴다. 임의로 장수를 바꾸지 않는다.
제목만 순서대로 읽어도 내용이 전진해야 한다. “무엇이 달라졌나 / 왜 중요한가 / 앞으로 지켜볼 점” 같은 목차나 “먼저 알아보겠습니다 / 마지막으로 정리합니다” 같은 진행 멘트를 독자용 제목·bridge로 쓰지 않는다. bridge가 필수라면 다음 장이 실제로 답하는 구체적인 쟁점을 쓴다. 같은 결론을 표현만 바꿔 반복한 장은 새 근거로 교체하거나 원고를 보류한다.

## 4. 글을 덜어내고 설명을 남긴다
글자 수 상한을 채우지 않는다. 3장 속보는 제목을 뺀 body + items의 label/text 합계를 장당 180자 이내로 목표한다. 본문 40~70자, 항목당 설명 15~40자부터 작성한다. 필요한 단위·기간·조건 때문에 초과하면 다른 정보를 먼저 덜고 다시 편집한다. 현재 코드의 필수 항목 수와 최소 길이는 지킨다.
5장·7장도 각 장에 하나의 주장과 새 근거만 둔다. 표에 쓴 숫자를 본문·takeaway·bridge에서 반복하지 않는다. 7장 형식을 채울 독립적인 근거가 없으면 해당 후보를 건너뛴다.
한 장의 큰 숫자는 핵심 비교 한 쌍으로 좁힌다. 판단에 필요하지 않은 HPC·CAPEX·GAAP 같은 용어와 소수점·수치 나열은 뺀다. 꼭 필요하면 첫 등장 때 쉬운 말로 설명한다.
출처·사실과 전망의 구분·결론을 바꾸는 단서는 해당 주장 옆에 유지한다. 다만 "보장하지 않습니다" 같은 일반적인 단서를 장마다 반복하지 않는다. 비교 대상을 정확히 적으면 해결되는 오해는 처음부터 정확하게 쓴다.
문장에 길이 차이를 둔다. 짧은 판단 한 문장 뒤에 필요한 이유를 설명하되, 모든 장을 같은 “A지만 B입니다” 또는 질문형으로 만들지 않는다. “중요합니다·주목해야 합니다·지켜봐야 합니다”를 쓰고 싶으면 무엇이 왜 달라지는지로 바꾼다. 재치는 정확한 대비와 관찰에서 만들고, 억지 밈·피해자 희화화·공포·가짜 대사·내부자 행세는 하지 않는다. 한 편의 비유는 필요할 때 하나만 쓰며 실제 거래 구조와 다르면 버린다.
느낌은 문장과 여백으로 만든다. 사진은 주장을 설명할 때만 쓰고, 관련 없어도 멋있다는 이유로 넣지 않는다. 기존 렌더러가 지원하는 비교·숫자·도식 안에서 시각적 리듬을 만들고 글씨를 줄여 밀어 넣지 않는다.
문장은 계정 주인이 독자에게 직접 설명하는 짧은 존댓말로 쓴다. "있어요~ / 봐요 / 함께 알아봐요", 보고서식 명사 나열, 과장된 개인 경험은 사용하지 않는다.

## 5. 마지막 장은 판단으로 끝낸다
"다음 실적을 확인하세요"만으로 끝내지 않는다. 현재 사실이 어떤 해석을 지지하는지 한 문장으로 답한 뒤, 그 해석을 바꾸는 가장 중요한 지표와 비교 기준 하나를 남긴다.
기업의 매출·비용 근거만으로 주가 방향을 단정하지 않는다. 현재 가격 반응·시장 예상과의 차이가 핵심인 글은 해당 데이터를 실제로 확인한다. 미확인이면 확인된 사업 변화 범위에서만 결론을 쓴다.
국내 기업 연결이나 수혜주 나열을 의무로 삼지 않는다. 납품·주문·가격 연결 근거가 없으면 다른 기업 이름을 억지로 붙이지 않는다.
캡션은 카드의 핵심 해석을 짧은 1~2문장으로 전달한다. "3장에 담았습니다", 형식 소개, 작업 보고, 같은 제목 반복은 뺀다. 해시태그는 2~3개다.

## 6. 제출 전 편집 판정
원고를 처음 보는 독자라고 생각하고 별도로 다시 읽는다. 아래 하나라도 실패하면 원고를 고치거나 게시를 건너뛴다.
1. 표지에 주체·구체적인 쟁점·읽을 이유가 있는가? 회사명만 바꾸면 다른 뉴스에도 그대로 붙는 제목이면 실패다.
2. 첫 두 장에서 제목의 약속을 지키는 답과 독자에게 중요한 이유를 얻는가? 호기심을 끌고 정의·주의사항만 나열하면 실패다.
3. 제목만 이어 읽어도 이야기가 전진하고, 각 장이 앞 장에 없던 근거·설명을 추가하는가? 장 하나를 빼도 잃는 정보가 없으면 다시 쓴다.
4. 끝 문장에 이번 사건만의 현재 판단과 그것을 바꿀 기준이 있는가? 뻔한 상식·“지켜보자”·팔로우 요청만 남으면 실패다.
5. 숫자·비교 대상·날짜·인과·제목의 대비까지 원문 근거가 있는가? 실제로 확인하지 않은 시장 예상·주가 원인을 흥미를 위해 보태면 실패다.
6. 실제 최종 이미지 전체를 휴대폰 크기로 봐도 읽히며 문장·정보 배치의 반복이 없는가? 제목·본문·항목이 같은 말이거나 사진이 메시지와 어긋나면 실패다.

최근 5편과 제목의 문형·시작 방식·마무리를 비교한다. “늘었는데 왜 줄었나” 같은 대비형도 연속 복제하지 않는다. 수정 후 제목만, 그다음 본문 전체를 따로 읽어 흥미와 정확성을 함께 점검한다.
summary.editorial_review의 기존 필드 안에 선택한 제목 관점과 탈락시킨 후보의 이유, 독자가 놓칠 대목을 어느 장에서 풀었는지, 최근 글과 달라진 전개를 구체적으로 남긴다. 새 JSON 필드를 임의로 추가하지 않는다.
summary.editorial_review에는 자화자찬 대신 이번에 버린 정보, 남긴 핵심 주장, 중복을 없앤 위치를 구체적으로 기록한다. 출처 사실검증과 코드 검증, preview 이미지 전체 검수는 서로 대신할 수 없다.
검수했어도 내용을 바꾸면 새 preview가 필요하다. 게시 완료/결과 불명확 원고는 수정·삭제·재게시하지 않는다.

## 실제 편집 예시 — 재게시 금지

- 기존 표지: TSMC, 4분기 매출도 14% 성장 전망
- 편집 표지: TSMC, 더 팔았는데 / 이익률은 왜 낮아졌나
- 초점: 첨단칩 수요 확대와 2나노 초기 양산에 따른 이익률 부담을 분리한다.
- 덜어낸 내용: 직접 증명되지 않는 국내 납품 수혜 확장, HPC 비중, 반복되는 수익 보장 부정문.
- 근거: TSMC 2026-10-15 3Q26 Earnings Release와 Management Report. 전분기 대비 달러 매출 +16.2%, 매출총이익률 67.7%→66.4%, 회사가 밝힌 2나노 초기 양산 영향. 4분기 매출·이익률은 실적이 아닌 회사 전망이다.
이 예시의 반전형 제목을 모든 소재에 복사하지 말고 편집의 밀도와 근거 연결만 참고한다.
